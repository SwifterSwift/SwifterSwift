# ``SwifterSwiftUIKit``

Extensions for UIKit.

## Overview

These extensions are available on iOS, iPadOS, tvOS, visionOS and Mac Catalyst. Extensions for UIKit types that also exist on watchOS, such as `UIColor` and `UIImage`, are available there too. On other platforms, the module is empty.

Every extension lives in its own source file and doesn't depend on any other SwifterSwift code. Use the whole module, or copy a single file into your project.

```swift
import SwifterSwiftUIKit

let card = UIView()
card.addSubviews([titleLabel, subtitleLabel, imageView])
```
